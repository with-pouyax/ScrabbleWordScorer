# Scrabble word scorer

**CS50 C exercise** · Scores two words with a fixed letter-point table and reports the higher-scoring player or a tie.

## Build and use

```sh
clang ScrabbleWordScorer.c -lcs50 -o scrabble
./scrabble
```

The executable uses the example or prompts shown in the source.

## Implementation note

This is a CS50 C exercise. Words are entered at prompts; scores are case-insensitive.
